# Repository instructions

- This repository is installed directly from GitHub. Keep `lib/` tracked and rebuild it whenever source or build configuration changes.
- Preserve the original MIT license and upstream attribution.
- Keep package identity, host plugin name, browser module id and bundle patch aligned as `dsh-sidechat`.
- Do not commit dependencies, test output, credentials or local environment records.
- Run the smallest relevant check; package changes require build and package integrity checks. Verify installation in an isolated profile.
